COMP 3005 Assignment 3

Create a database in pgAdmin for creating the table inside Postgres
Create the students table:
create table students
	(student_id		INT NOT NULL GENERATED BY DEFAULT AS IDENTITY,
	 first_name		varchar(25) NOT NULL,
	 last_name		varchar(25) NOT NULL,
	 email			varchar(25) NOT NULL UNIQUE,
	 enrollment_date	DATE,
	 primary key (student_id)
	);

Then insert the data into the table:

INSERT INTO students (first_name, last_name, email, enrollment_date) VALUES
('John', 'Doe', 'john.doe@example.com', '2023-09-01'),
('Jane', 'Smith', 'jane.smith@example.com', '2023-09-01'),
('Jim', 'Beam', 'jim.beam@example.com', '2023-09-02');

Pre-requisite - Must have Maven setup
Open the file/repository
